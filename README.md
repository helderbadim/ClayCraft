# ClayCraft 🏺🎨

Welcome to **ClayCraft**! This project showcases an interactive webpage focused on the art of pottery and clay crafting. It is designed with a visually appealing interface to engage users and highlight the beauty of clay craft.

## 🚀 Live Demo

Explore the live demo here:  
https://helderbadim.github.io/ClayCraft/

## 📌 Features

- **Beautiful Design**: A modern and clean aesthetic to present the art of clay crafting.
- **Responsive Layout**: Optimized for various devices, including desktops, tablets, and mobile phones.
- **Interactive Content**: Engaging features to captivate users and enhance their experience.
- **Informational Sections**: Highlighting the process, tools, and creativity behind clay crafting.

## 🛠️ Technologies Used

- **HTML5**: For creating the structure of the webpage.
- **CSS3**: For styling the layout and adding visual appeal.
- **GitHub Pages**: For hosting the live demo.

## 📂 Project Structure

ClayCraft/

  - style.css        # Main stylesheet
